<h3>📌 Notable Projects</h3>

- **[ComTrike](https://github.com/VONGoldilux/Complain-Impact)** — Lead developer. Capstone project: a web-based complaint management system for tricycle commuters in Lipa City. Separate LTO and LGU officer dashboards, public-facing complaint filing, split-jurisdiction routing, and data retention/disposal handling under the Philippine Data Privacy Act. Built with Supabase (PostgreSQL, RLS, Edge Functions), vanilla JavaScript, and Bootstrap 5. Deployed on Vercel.

- **[Fedelicious Wings POS](https://github.com/VONGoldilux/Fedelicious-Wings-POS-)** — POS and analytics system for my family's restaurant. Redesigning the Dashboard, Analytics, Transactions, Staff, and Payroll pages with Fluent UI.

- **[Garcia's Auto Supply POS](https://github.com/Drei-Nitsu/Garcia-s-Auto-Supply)** — POS system for a friend's auto supply shop. Built with React, Tailwind CSS, and Supabase, including a pricelist import feature.
